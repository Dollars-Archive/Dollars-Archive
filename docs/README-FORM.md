# 한글패치 대문 공통 양식

게임 정보와 현재 한글화 상태는 **게임 저장소의 README.md 한 곳**에서 수정합니다.

1. README의 편집 버튼을 눌러 게임 정보 표와 다섯 항목의 숨김 주석 `kr-patch:state:`를 수정합니다.
2. 저장하면 허브가 매시 23분 예약 실행 때 해당 README를 수집합니다. GitHub 예약 실행은 지연될 수 있습니다.
3. 즉시 수집하려면 허브 저장소 Actions → Update Korean patch hub → Run workflow를 실행합니다.

허브를 새로고침하면 README를 포함한 저장소의 마지막 푸시 시각도 다시 확인해 최근 작업 정렬에 반영합니다. 화면은 날짜만 표시하지만 같은 날짜 안에서도 실제 시각 순으로 정렬합니다. 프로필과 저장 데이터는 정기 수집 때 갱신됩니다.

신규 게임은 [공통 템플릿](../templates/README.template.md)을 복사하고 저장소 이름·게임 정보를 채운 뒤 `kr-patch` topic을 붙입니다. 게임 정보·현재 범위를 허브의 `patches.yml`에 중복 입력할 필요는 없습니다. 표지 출처와 버전별 변경 이력은 기존 방식으로 `patches.yml`에서 관리합니다.

## 게임 정보

표의 항목 이름과 `kr-patch:game-info:v1` 주석을 유지합니다. 개발사·장르·발매일·플레이타임을 포함하며, 플랫폼이 여러 개면 `PC / Nintendo Switch`처럼 `/`로 구분합니다. 날짜는 `YYYY-MM-DD` 또는 `YYYY년 M월 D일`로 입력합니다.

한글 제목·원제·시리즈·플랫폼·개발사·발매사·장르·장르 상세·일본 발매일·플레이타임·지원 판본·Title ID·제품 번호·패치 기준 업데이트를 읽습니다. CERO 등 추가 행은 대문에 그대로 둘 수 있습니다. 값에 `|`가 들어가면 `\|`로 씁니다. `—`는 빈 값으로 처리합니다.

## 한글화 상태

허브의 이미지 칸은 체크되면 항상 녹색 `이미지 ✓`로 표시합니다. 노란색 `이미지 일부` 표시는 사용하지 않습니다. 체크되지 않은 항목은 `이미지 —`로 표시합니다. 이 규칙은 신규 프로젝트에도 적용합니다.

다섯 제목은 `타이틀 한글화`, `메뉴·UI`, `대사`, `이미지 번역`, `동영상 자막`으로 고정합니다. 상태는 공개 문구로 쓰지 않고 각 제목 아래의 HTML 주석에 입력합니다. 기존에 삭제한 상태 문구는 복원하지 않아도 됩니다. 릴리스의 해당 버전 변경 항목 또는 `v1.1에는 … 자막을 추가했습니다`처럼 버전을 명시한 소개 문장에 추가 내용을 적으면 허브가 체크와 도입 버전을 계산합니다.

```markdown
## 메뉴·UI

<!-- kr-patch:state: 완료 -->
```

- `완료`: 체크 표시
- `일부`: 일부 표시
- `미작업`: 체크 없음
- `해당 없음`: 체크 없음, 설명에 해당 없음 표시
- `확인 필요`: 기존 자료로 판단할 수 없는 항목. 확인 후 위 네 가지 중 하나로 바꿉니다.

제목 아래에는 기존 스크린샷·설명·하위 제목을 자유롭게 유지합니다. 제목이나 스크린샷이 있다는 이유로 완료로 판단하지 않습니다. `kr-patch:scope:v1` 주석을 삭제하지 않습니다. 잘못된 입력은 내부 경고로 남기고 해당 부분의 기존 데이터를 유지합니다.

README의 숨김 상태를 우선하되 최신 릴리스에 명시된 추가 기록은 이전 README 상태보다 우선합니다. 새로고침 때 최신 릴리스와 첨부파일·최근 작업·추가 범위도 함께 갱신합니다. 체크 칸에는 현재 상태만 표시하고 버전 숫자는 붙이지 않습니다. 버전과 추가 내용은 아래 변경 이력에서 확인합니다. 공개 관리 경고 영역은 계속 숨깁니다.
